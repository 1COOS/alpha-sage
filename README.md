# Alpha Sage

Alpha Sage 是一个本地单用户、证据优先、自我学习进化的 A 股模拟投资 Agent。它不采用因子工厂、参数海选或高频交易框架，而是持久执行：

`观察 → 研究 → 反驳 → 决策 → 模拟交易 → 归因 → 经验 → 挑战者`

V1 覆盖沪深流动性股票与宽基/行业 ETF，模拟资金 100 万 CNY，仅多头、无杠杆、允许持币。系统不会连接真实券商，不会在运行时修改代码，也不会自动晋升挑战者。

## 已实现能力

- Eastmoney + BaoStock 五年日线、交易日历、股票与 ETF 精选池同步；Eastmoney 不可用时可由腾讯不复权日线与 BaoStock 保持双源确认。
- Eastmoney 5 分钟行情 + 腾讯报价双源确认；冲突超过最小价格变动单位即阻断。
- 正方研究、反方质疑、三周期综合裁决与不可覆盖的决策修订链。
- 下一根完整 5 分钟行情模拟成交、10bp 滑点、佣金、印花税、过户费、T+1、整手和涨跌停规则。
- 单标的 10%、行业 25%、总仓位 85%、12% 降仓和 18% 暂停新开仓硬门禁。
- 归因、SQLite FTS5 情景检索、周度规律、冻结留出回放、20 交易日影子运行、人工晋升与回滚。
- 本地 Next.js 工作台、持久任务中心、按钮就地反馈、SSE 对话、模型与来源设置、手动启停。
- 推理模型与快速模型独立真实连接测试；测试使用未保存表单且不会保存临时 API Key。
- SQLite WAL 业务账本、Parquet 原始/确认数据封存、DuckDB 查询和追加式审计链。

## 快速开始

要求：Python 3.12、`uv`、Node.js 20+、pnpm 10+。

```bash
cp .env.example .env
make install
make init-db
```

启动两个本地进程：

```bash
make dev-api
make dev-web
```

浏览器打开 `http://localhost:8888`。先在设置页填写 OpenAI 兼容模型地址、模型名和 API Key，并点击“测试连接”；两个模型均通过后再保存设置并执行五年历史同步：

```bash
make sync-history
```

同步完成后执行：

```bash
make preflight
```

只有模型、精选池、双源历史、交易日历、交易规则和关键来源全部通过，界面中的“自检并启用”才会启用模拟账户。初始化账户始终保持暂停；系统不会生成 Demo 行情、持仓或成交来绕过门禁。

## 数据与模型提示

免费公开数据没有 SLA。接口不可用、双源冲突、日历缺失、规则版本缺失或模型故障时，系统会阻断受影响任务并保存原因，不会猜测执行。模型失败会保留阶段、模型、耗时、错误分类和脱敏消息。API Key 优先从本机环境读取，也可保存在操作系统密钥环；密钥不会写入数据库或回显到页面。
