# 数据、风控与安全边界

## 数据来源

- 日线和交易日历：Eastmoney + BaoStock；Eastmoney 不可用时，以腾讯不复权日线与 BaoStock 继续双源确认，并明确标记回退。
- 盘中 5 分钟行情：Eastmoney；腾讯报价用于成交价格确认。
- 公告与事实：上交所、深交所、巨潮资讯以及配置的公司投资者关系页面。
- 宏观与产业：证监会、央行、统计局、发改委、工信部及白名单财经媒体。

免费公开来源没有 SLA。来源健康只说明最近一次受控任务结果，不代表未来可用性。

## 数据门禁

- 股票与 ETF 日线统一为不复权口径后比较。
- 关键 OHLC 差异超过标的最小价格变动单位时，该交易日不进入确认数据。
- 盘中成交前，5 分钟收盘价与独立报价差异超过最小价格变动单位即阻断。
- ST、退市整理、停牌、上市不足 120 日和流动性不足标的不进入精选池。
- 股票 20 日中位成交额门槛 5,000 万元；ETF 门槛 2,000 万元。
- 原始数据和双源确认数据分别封存，包含获取时点和内容哈希。

## 交易与回撤规则

- 仅多头、无杠杆、允许持币。
- 单标的合并敞口不超过 10%，行业不超过 25%，总仓位不超过 85%。
- 12% 回撤进入强制降仓状态：禁止盘中加仓，盘后目标总仓位压到 60%以内。
- 18% 回撤暂停新开仓；硬风控卖出仍可执行。
- 模拟成交使用下一根完整 5 分钟行情、10bp 不利滑点、万分之三佣金且最低 5 元。
- 股票卖出税费和过户费来自带生效日期的 `MarketRuleVersion`；成交保存规则版本、币种、UTC 时间和交易所本地交易日。

## 模型安全

- 仅把研究所需的受控上下文发送给配置的模型 API。
- 模型不能直接写成交、启用账户、修改硬风控、晋升策略或改写历史记录。
- 模型响应必须通过 Pydantic 结构契约；连续不合规或不可用会使任务失败并记录原因。
- 每日模型请求预算在调用前强制检查。
- API Key 不写 SQLite；优先使用操作系统密钥环。

## 进化隔离

- 日常经验自动追加并进入 FTS5 检索。
- 周度规律仅是候选，不能修改冠军行为。
- 月度挑战者只能修改规则、证据权重和提示词，不能生成或执行代码。
- 按时间顺序冻结最近 20%且至少 20 个案例作为留出集；生成挑战者时不提供留出结果，也排除引用留出案例的周度规律。
- 冠军与挑战者使用同一模型、同一无结果案例和同一评分条件回放。
- 历史门槛通过后还需至少 20 个交易日影子运行，并满足净超额、回撤、校准和零硬风控违规条件，最后由用户人工批准。
